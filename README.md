# Pelican Creek Realty

A responsive Next.js website for Pelican Creek Realty, featuring the Nyeredzi Ridge House development and the company’s leadership team.

The home visual for Nyeredzi Ridge is an AI-generated artist’s impression. It is clearly labeled and does not represent a photograph of the finished property.

## Run locally

Install dependencies with `npm install`, then start the development server with `npm run dev`. Open `http://localhost:3000` in a browser.

Use `npm run build` to create a production build and `npm run start` to serve it.

Set `NEXT_PUBLIC_SITE_URL` to the verified production origin before building for deployment. This adds the canonical URLs, sitemap host, and social preview image. Leave it unset for local development.
